WHAT WAS BUILT
================================================================================

A quality scoring system that applies multipliers (0.5x to 2.0x) to intimacy 
progression based on interaction quality. This prevents spam and rewards 
thoughtful engagement.

Key Features:
- Scores messages from 0.5x (spam) to 2.0x (exceptional)
- Analyzes length, questions, personal sharing, memory references
- Detects spam patterns, generic phrases, lazy typing
- Tracks conversation depth for better scoring
- Logs exceptional interactions for monitoring
- Fully backward compatible (default 1.0x)

HOW IT WORKS
================================================================================

Before:
  User sends message → +1.0 to interaction_count

After:
  User sends message → Quality scored → +0.5 to +2.0 to interaction_count

Examples:
  "lol"           → 0.5x (minimal)
  "hey ika"       → 1.0x (normal)
  "hey ika, how are you today?"  → 1.5x (high)
  "i've been thinking about what you said..." → 2.0x (exceptional)

================================================================================
IMPACT
================================================================================

User Experience:
- Spam users: Progress 40% slower (~167 messages to devoted)
- Normal users: Same speed (100 messages to devoted)
- Thoughtful users: Progress 60% faster (~63 messages to devoted)
- Exceptional users: Progress 100% faster (50 messages to devoted)

System Performance:
- Minimal CPU impact (simple regex/string operations)
- No memory overhead (no persistent storage)
